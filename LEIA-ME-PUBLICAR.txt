PROTEGE V5 - PUBLICAÇÃO

1. NÃO envie o ZIP diretamente para o GitHub.
2. Extraia o ZIP.
3. No GitHub > Add file > Upload files, envie TODOS os arquivos da pasta extraída.
4. Confirme Commit changes na branch main.
5. Aguarde 1-3 minutos e atualize o site com Ctrl+F5.

IMPORTANTE: para que os cadastros funcionem entre computadores/celulares, configure o Supabase conforme README.md. Sem Supabase, a V5 funciona em modo de teste local no mesmo navegador.
